# Project and artwork notices

No open-source license has been selected for this private project. The npm package is marked `private` and `UNLICENSED`.

The twelve cat packs contain original artwork generated with OpenAI ImageGen. Their prompts are retained under `docs/art-prompts`; each pack also contains an artwork notice. The diagnostic starter artwork has its own CC0 notice.

Imported personal Alphonse artwork and Pokémon assets are not included. This repository also excludes original migration records, private local history, live-session evidence, credentials, runtime state, and compiled binaries.
